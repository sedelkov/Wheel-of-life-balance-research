## Что это

Интерактивный сайт-исследование «Колесо баланса жизни: критический анализ» — насколько методика валидна для людей с ограниченными ресурсами (время, деньги, энергия), по обзору 65+ эмпирических работ. Есть интерактивное колесо, опрос, симулятор Gap Framing, тест на выученную беспомощность, генерация PDF-отчёта (`html2pdf.js`), языки ru / en (i18next). Стек: Vite + React 18 (JSX, без TypeScript) + Tailwind 4 + shadcn/ui + Recharts + Framer Motion. Сделан в Manus, доработан агентом Jules (PR #1). Опубликован на Manus (ссылка в README). Состояние — готовый сайт, бэкенда нет.

## С чего начать

1. `README.md`, затем `src/App.jsx` и `src/locales/*/translation.json`.
2. Зависимости: `pnpm install` (lock-файл — `pnpm-lock.yaml`).
3. Тестов нет. Проверка: `pnpm lint && pnpm build`.

## Карта кода

| Путь | Что там |
